# 湘南・山梨親子鐵道旅行 · 2026/11/19–11/22

目前版本：**v1.1.1**。變更詳見 [CHANGELOG.md](CHANGELOG.md)。

四天行程、整體 Google Maps 地圖、每日分段交通、可編輯的住宿／機場／租車與三餐候選。

## 免安裝下載版

下載 `standalone.html`，使用瀏覽器開啟即可，無需 Python。內含總覽示意圖、四天行程及餐飲候選。可修改本機草稿、匯出 JSON 交給同行家人匯入，不會跨裝置自動同步。Google 即時地圖仍需要網路。部分手機的檔案預覽器不執行 JavaScript，需用支援 HTML 的瀏覽器開啟。

## 啟動共用版

需要 Python 3.12+，不需安裝第三方套件。

```sh
cd /workspace/Japan-trip-Nov2026
TRIP_DATA_DIR=/workspace/trip-runtime python3 server.py --host 127.0.0.1 --port 8001
```

首次啟動在資料目錄產生隨機家庭密碼 `access-code`（僅擁有者可讀）和 SQLite 行程資料庫。請由管理者安全讀取密碼並私下交給同行家人，不要提交 Git、公開貼出或放在網址。也可透過伺服器的秘密設定注入至少 12 字元的 `TRIP_ACCESS_CODE`。網站沒有預設公開密碼。

兩人使用同一個共用版網址、登入同一家庭密碼，再選「爸爸」或「媽媽」作為編輯署名。這是家庭共用權限，不是兩個獨立身分帳號。修改後按儲存；另一台按「載入共用最新版」更新，沒有即時推送。若兩人從相同版本修改，後儲存者會收到衝突提醒，原草稿保留於畫面；先下載草稿，再載入最新版重新套用，避免覆蓋對方的修改。登入工作階段為 12 小時，伺服器重啟需重新登入。

資料存在 `TRIP_DATA_DIR/trip.sqlite3`，重啟不會重設。請備份整個資料目錄（先停止伺服器或用 SQLite 備份 API），不要把資料庫放在公開網站目錄或 Git。`trip.json` 只作為新資料庫的初始行程，不會覆蓋既有共用資料。

### 上線讓兩支手機使用

需要支援長時間 Python 程序與持久磁碟的主機。GitHub Pages 只支援靜態內容，無法執行此共用後端。對外部署時，以 HTTPS 反向代理轉送到此服務，設定 `TRIP_SECURE_COOKIE=1`，保留資料目錄；僅在受保護的容器／代理網路需要時使用 `--host 0.0.0.0`。不要直接把未加密的 HTTP 服務公開到網際網路。目前開發環境內的服務不代表已部署或有可分享的公開網址。

## 靜態版

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

靜態版可瀏覽、編輯本機草稿及下載／匯入 JSON，但不會跨裝置同步。頁面會明確顯示模式。草稿含住宿與行程資訊，只應分享給家人。匯入共用版後仍需按儲存。

## 地圖與餐廳

- 頁面內建不依賴外部服務的 SVG 四天移動總覽，按日期可聚焦路線，交換活動日期後同步更新；未定位地點會另列。此為相對方位示意，非精確道路地圖。
- Google 地圖不需要 API key。整體嵌入地圖與外開道路路線呈現主要地點；每日可點選相鄰站點，切換開車／大眾交通／步行導航。
- 未確認的機場、飯店、取還車據點不會被假定成實際位置。未選飯店時，整體地圖以海老名站代表住宿區域。
- 湘南單軌與江之電是體驗目的；Google 可能推薦其他交通方案，應以行程備註與官方班次為準。多站點外開路線受 Google Maps 裝置／站數限制，請用每日分段導航核對。
- 三餐各提供兩個初始候選。機場未定的餐次保留航廈選項；店家資訊、營業、兒童設施、過敏原與預約需出發前核實，沒有宣稱已訂位。
- Google 地圖需使用者瀏覽器連網。嵌入受阻時可用外開連結。自動化測試攔截外部地圖請求，只驗證地圖網址及操作，未驗證 Google 的即時路線／店家營業。

## 驗證

```sh
python3 -m unittest test_server.py
node --check app.js
```

整合測試在暫存資料目錄啟動獨立服務，涵蓋登入、未授權拒絕、兩人修改衝突、資料格式驗證、私有檔案阻擋、重啟後保留資料與登出。瀏覽器驗證另涵蓋四天／24 個餐飲選項、兩個工作階段、分段地圖模式、餐廳加入路線、活動換日、手機版與靜態備援模式。
